3 步安装

Chrome 非商店扩展需要「开发者模式」加载，一次装好，之后自动用。

1
下载并解压
点上面的「下载插件」，把下载到的 zip 解压，得到一个文件夹。
2
打开扩展页，开「开发者模式」
Chrome 地址栏输入 chrome://extensions 回车，打开右上角的「开发者模式」开关。
3
加载已解压的扩展程序
点「加载已解压的扩展程序」，选中第 1 步解压出的文件夹 —— 装好了。
✓
开始用
在浏览器登录你要追的平台网页版，点插件图标 →「同步」。
💡 每次重启 Chrome 可能提示「要停用开发者模式扩展吗」，点保留/取消别停用即可。这是 Chrome 对非商店扩展的常规提醒。

它能做什么

6 个平台的收藏/点赞，后台悄悄同步，攒成一份待看清单。

🔔 后台自动同步
定时检查各平台新收藏，角标 + 通知提醒，不用你手动翻。
🎯 按平台单独同步
同步按钮带下拉，可只同步某个平台，并显示各自上次同步时间。
📤 一键导出 CSV
整个清单导成表格，Excel 直接打开，来源/标题/链接一应俱全。
🔒 纯本地不上传
所有数据只存你自己浏览器，抓的是你自己账号的收藏，不经服务器。
